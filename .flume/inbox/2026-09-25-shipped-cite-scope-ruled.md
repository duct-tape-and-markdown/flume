# Ruled: the shipped-cite rule is scoped by where the page is read

Answers `questions/does-the-shipped-cite-ruling-reach-a-docs-page-and-the-readme.md`.
(b), with the rationale corrected so it no longer overreaches. The earlier
ruling's reason ("the install carries") covered every packed page. The real
line is where the reader stands. The template, the prompts, and the help
literals are read inside a consumer's tree or terminal, where no spec corpus
exists. A `docs/` page and the README are read where flume's own repository
resolves them: a checkout, the forge, or the registry page that links back.
Their spec citations resolve for that reader and stand.

`spec/harness.md`, *Adoption and upgrade* now says both halves (this
ruling's commit). `THE-SHIPPED-PAGE-CITE-RESOLVES-AGAINST-THE-PACKED-SET`
keeps its scope of the three kinds. No new entry, and the 61 docs and README
