# Ruled: the authoring page owes one level beneath each declaration field

Answers `questions/which-nesting-depth-does-the-authoring-page-owe.md`: (2)
with (3)'s reason. What the page owes is what an author types by hand, and
for the fields the package ships that is the top-level field and the level
beneath it; a consumer's own keys — the phases under `fence` — are not the
package's to name. `.claude/rules/engineering.md`, *Narration is the
ladder's bottom rung* says so (this ruling's commit). File the walk.
