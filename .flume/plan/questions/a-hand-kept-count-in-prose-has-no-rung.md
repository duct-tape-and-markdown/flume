# A hand-kept count in prose has no rung, and this is its third note

Three `plan:` bodies have now accepted the same shape as debt: a doc comment
or page that **counts** or **names the target of** a set the program holds —
"every caller here but one", "build's two notes", "exactly one caller to
share it through" — and goes stale when the set moves, while every token it
names still resolves. The citation pin reads the token and never its meaning
by design (`engineering.md`, *Narration is the ladder's bottom rung*), so the
pin is green and the sentence is false.

Sightings: `88a78569` (`harness/sliceWindow.ts`, a two-module caller count
over three call sites); the `isDotName` sharer count, which named itself the
second; and now `src/waveMerge.ts`'s "every caller here but one", which went
stale when a second base-reading leg landed. Each site was repaired in the
commit that noticed it, so **nothing stands on disk** — the cost is the
re-noting, which is what the three-notes bar exists to end
(`spec/harness.md`, *The sweep procedure*).

**The decision, because every arm lands outside a build tick's reach or was
measured noisy.**

- **(a) A suite arm.** Resolve count-naming spans against the set the
  TypeScript program holds. The one scan anyone has run over this class found
  **36 count-naming spans, of which 1 was a stale roster** — so the arm is
  high-noise, and `engineering.md` warns that "every arm is a generator of
  the next".
- **(b) A sweep lens.** One bulleted lead under `posture-sweep.md`, *Standing
  lenses*, read per neighborhood where a human already reads the prose.
  Cheap, no false positives, no mechanical guarantee. Lands on a rule page,
  which only a human edits.
- **(c) Rule it closed.** State on `engineering.md` that a count is a meaning
  rather than a token, so it stays at the bottom rung by construction and a
  later note cites that ruling instead of re-deriving it. Subtraction, and it
  ends the family's accounting.

Plan's read: (c) or (b). (a) is the only arm a build tick could ship and the
measured ratio argues against it, which is why this is a question rather than
an entry — the three-notes remedy the bar prescribes has no standing site to
name in `files`.
