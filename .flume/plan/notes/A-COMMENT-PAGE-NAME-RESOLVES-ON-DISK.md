# A fixture's own page name has no home under the widened arm

The arm reds every `*.md` citation the working tree cannot answer, fixture
paths included: `notes/park.md`, `note.md`, `spec/bad.md`, `docs/x.md` all
name files a test builds in its own temp repo. Those comments lost the
filename (the literal sits a line below) rather than take an
external-vocabulary entry, which is keyed by bare text and would excuse
`note.md` repo-wide. `SHIPPED.md` did take one: declared in `examples/`,
a tree the carve-out does not judge — the list's own stated rationale.

Asymmetry for plan: the arm is scoped to `*.md`, so `src/stray.ts` in the
same Gate.test.ts comment still resolves off its literal while `spec/bad.md`
beside it reds. Same defect, verdict split by extension. Widening the path
arm the same way would red every fixture `.ts` path in the suite, so it is
plan's call.
