# The roster was three sentences, not one

The roster the entry names sat in the opening sentence, but two later
paragraphs carried the same copy in other clothes: the "pair, not the step"
paragraph illustrated itself with "arming a rotation, extending a covered
set", and the silent-failure paragraph closed on "a cursor stamped under an
open rotation, or a covered set shrunk while one stands open" — the sweep's
two rules restated as failure modes. Both are gone; the failure paragraph now
states the two ancestry halves' own losses and points at the table for the
rest.

Two verbs remained that would have grown with a fourth slice: "commits nobody
derived or swept" and "was one this tick actually derived or swept". Both now
read "that slice's work", so the doc holds no per-slice enumeration at all.

Worth knowing: `harness/planState.ts`'s `SLICE_STATE_RULES` header states
"derive's cursor is bounded by its step through history and by nothing its own
file says". That is the table's own home naming its own empty list, so it is
not a second copy — but it is one sentence a fourth slice with no rule would
want to join, and if a second empty list lands it becomes one.

No test or pin: the comment sits on an internal function, reachable from no
`.d.ts` the `exports` map ships, so the citation pin is the only mechanical
reader and it resolves tokens, not claims.
