header claims "Both cases read the verb set off the surface rather than
restating it". Only the `--help` case does; the docs case loops a literal

the generalization the header already promises: drive the docs case off
`topLevelCommandNames()` and drop the literal. Not taken here - it would
retitle a shipped pin and widen the claim to every verb section.

others", which loop's cause list carries, is unreachable today:
`artifactsNamedIn` reads backticked path segments, and the page names two
