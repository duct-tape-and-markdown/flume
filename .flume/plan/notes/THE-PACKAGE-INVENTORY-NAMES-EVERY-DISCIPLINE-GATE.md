a sixth gate reds until the page names it. The page also says "the five
discipline gates", and `tests/harnessGates.test.ts`'s module header says

while the name pin is what goes red, and the fixing commit has to notice the
word by hand. Filing as shape, not an entry - the cheap fix is dropping the
number from both ("the discipline gates that run ahead of...") rather than
pinning it. Plan's call whether that is worth an entry.
